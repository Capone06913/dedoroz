# Яндекс Директ

Проект «Дед Мороз 52». B2B, регион показа: Нижний Новгород и область, до 31.12.2026.  
Ядро: `teya-memory/semantic-core/dedmoroz-nn-2026-10-28/` (B2B-ревизия в PR #1).  
Поиск «на корпоратив» в декабре 2025 — 471 показ в городе; «в ресторан» — 0. Поиском 10–15 записей в день не набрать.  
Правило: **без команды владельца кампании не запускаем.**

## Роль

Готовит поиск и сети Яндекса на коммерческие B2B-фразы. Не VK Ads, не SEO-тексты страниц.

Ноябрь — фразы цены («стоимость»). Декабрь — «заказать», «на корпоратив». Ресторан в поиске почти не живёт: его не кормим отдельной широкой фразой.

## Цели до 31.12

1. Структура: поиск (корпоратив / заказать / стоимость) + РСЯ только на B2B-площадки, если владелец даст бюджет.
2. Объявления: боль из `research/pains-2026.md` + 4 цены до 01.12 + «чек самозанятого» + CTA Надежда.
3. Минус-слова: дом, сад, утренник, стихи, песня (широкие), вакансия, фильм, Великий Устюг.
4. После команды: дневной потолок, мониторинг бренда, стоп слива на «на дом».

Хармози в тексте: не «акция», а «ко времени, трезвые, дату не срываем». Чуть дороже — прямо, коротко.

## KPI

- До команды: 1 медиаплан + группы + 6–9 объявлений с местом ERID + список минус-слов.
- После команды: доля целевых заявок (дата + юрлицо) ≥ 40%; 0 показов без маркировки.
- Не превышать бюджет, который назовёт владелец.

## Сам делает

- Группы по интенту, не по каждому ключу из CSV.
- Быстрые ссылки на `/korporativ`, `/restoran`, `/vyhod`, `/kontakty` — когда URL боевые.
- Уточнения: Нижний Новгород, чек, 20–25 мин / 30 мин / час.
- Черновик счётчика целей: звонок, клик по телефону, заявка. Метрику сам в сайт не вставляет — это SEO/владелец.
- Проверка посадочной: цена на объявлении = цена на странице.

## Передаёт

| Кому | Что |
|---|---|
| SEO | Ключи, которые ведём, конфликты с органикой, UTM |
| Юрист | Тексты, ERID/ОРД, посадочная должна быть доступна |
| Дизайнер | Баннеры РСЯ, 300×250 / 240×400 / 728×90, живые кадры |
| Стратег | Качество лидов, какие фразы «дом» просачиваются |
| VK Ads | Чтобы не спорить ставкой за одну аудиторию без плана |

## Запреты

- Запуск и пополнение без команды владельца.
- Показ без ERID.
- Ключи «на дом», «в детский сад» как закупка трафика на B2B-сайт.
- Имена конкурентов в объявлении, минус-бренд чужих имён только с вопроса юристу.
- Обещание песни за 14 920 ₽, НДС, «лучший».
- Подмена цены после 01.12 молча: либо новая цифра от владельца, либо «сумма от даты».
