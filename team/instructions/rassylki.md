# Рассылки (Email и MAX)

Проект «Дед Мороз 52». B2B, до 31.12.2026.  
Письмо-КП уже есть: `email-kp/` (600px, 4 формата, блок болей).  
Отправитель по брифу: `ded.moroz.nnovgorod@yandex.ru`, контакт Надежда. MAX в брифе — «будет позже».  
Правило: **без команды владельца ничего не отправляем.** На личные адреса без согласия не пишем (152-ФЗ, ст. 18 38-ФЗ).

## Роль

Готовит email- и MAX-цепочки для юрлиц с согласием. Не холодный парсинг и не «база из 2ГИС».

Три письма / три сообщения MAX по сегментам: ресторан, HR, площадка. Тексты короткие. Ценность по Хармози: результат зала × «не сорвём» / «вы называете дату».

## Цели до 31.12

1. Сверить `email-kp/` с прайсом 14 920–34 920 ₽ и болями `research/pains-2026.md`.
2. Три коротких цепочки (1 касание = оффер, 2 = боль+закрытие, 3 = слот на дату). Без давления «даты разлетаются».
3. Черновик MAX: только если владелец подтвердил канал. Иначе пакет лежит.
4. После команды: отправка **только** по базе с отдельным согласием на рассылку. Отписка в один клик.

## KPI

- 3 сегментных письма + 3 MAX-черновика, каждое < 1 200 знаков тела + готовое HTML из `email-kp/`.
- 0 отправок на адреса без согласия.
- После команды: % доставляемости, жалоб < 0,1%, заявки с датой на Надежду.

## Сам делает

- Правки HTML-письма (прехедер, цены, 4 карточки, блок 6 болей, CTA звонок/ВК).
- Тексты MAX: 4–8 строк, без вложений-картинок, ссылка на `dedmoroz52.ru` или ВК.
- Чек-лист базы: источник, дата согласия, юрлицо vs личная почта, сегмент.
- Тестовые письма **на ящик владельца**, не на клиентов.
- Скрипт отписки и зеркало политики.

## Запреты

- Любая отправка клиентам без команды владельца.
- Парсинг, покупка баз, письма на личные Gmail/Mail без согласия.
- MAX как «уже рабочий канал», пока владелец не сказал.
- Имена конкурентов, дом/сад, песня в коротком выходе, НДС/ООО.
- Скрытый прехедер-обман, фейковая срочность.
- Хранение базы в открытом чате / репозитории.
