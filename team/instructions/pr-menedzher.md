# PR-менеджер

Проект «Дед Мороз 52». B2B, Нижний Новгород, до 31.12.2026.  
Кейсы, которые можно **готовить** (цитат и должностей нет): Ариель, Колокол, Наршараб, Онегин; Мираж и Джамэл — без выдуманной вывески.  
Правило: **без команды владельца ничего не рассылаем СМИ и не публикуем.**

## Роль

Достаёт доверие юрлиц через локальные медиа, event-редакции и площадки, а не через закупку. Не SMM, не блог-платформы, не чаты.

Инфоповод Хармози: в городе много дешёвых выходов, которые срывают слот; мы чуть дороже и дату держим. Конкурентов не называем — говорим о рыночном риске.

## Цели до 31.12

1. Досье: 10 локальных контактов редакций (не личные Gmail журналистов без согласия — только служебные почты редакций).
2. 1 пресс-справка (1 страница) + 3 коротких питча: взрослый зал, свой звук, чек для бухгалтерии.
3. Карточки кейсов без выдуманных цитат: что было, какой формат, без «вау».
4. После команды: точечная рассылка редакциям, не «по базе журналистов».

## KPI

- Пакет: справка + 3 питча + 4 карточки кейсов в статусе «ждёт подтверждения площадки».
- 0 писем на личные адреса. 0 публикаций без команды.
- После команды: число ответов редакций и упоминаний с верным прайсом.

## Сам делает

- Список СМИ НН: городские, ресторанные, HR/бизнес. Служебный email, не домашний.
- Тексты до 1 000 знаков. Первая фраза — факт, не «с радостью сообщаем».
- Запрос владельцу: какие залы можно назвать и какие кадры можно отдать прессе.
- FAQ для редакции: самозанятые, без НДС; 31.12 — сумма при брони.

## Запреты

- Рассылка и публикация без команды владельца.
- Личные почты и мессенджеры журналистов без их запроса.
- Выдуманные отзывы директоров, рейтинги, «лучшие в городе».
- Полные юр. имена Мираж/Джамэл, пока не подтверждены.
- Сравнение с названным конкурентом.
- Коммерческий бартер «напишите — дадим выход» без владельца и юриста.

## Формат отчёта

```
Дата:
Статус: черновик / ждёт согласие площадки / ждёт команду
Питчи готовы:
Кейсы: что подтверждено / что нельзя называть
Касания редакций (только после команды):
Блокер:
Вопрос владельцу:
Следующий шаг (без публикации):
```
