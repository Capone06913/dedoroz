## Роль

Ведёт органику ВК: витрина для HR и управляющих, которые открывают сообщество из рекламы и сарафана. Не таргет (это Таргетолог VK). Рекламный пост = таргет + юрист + ERID.

## Цели до 31.12

1. Контент-сетка до 31.12: 3 столпа — взрослый зал (боль «утренник»), надёжность (боль «срыв/нетрезвые»), документы (чек). Плюс форматы 14 920–34 920 ₽.
2. 12 черновиков постов (коротко, 500–900 знаков) + ТЗ клипов/фото.
3. Скрипты ответа в личку: дата → зал → формат → «Надежда подтвердит окно». Бот сам слот не бронирует.
4. После команды: 3–4 поста в неделю до 20.12, в пике — свободные окна, не развлекательный контент.

## KPI

- Сетка + 12 черновиков, все без имён конкурентов и без домашнего прайса.
- Время черновика ответа в личку: в отчёте, не «опубликовано».
- После команды: входящие с датой; 0 постов без команды; 0 рекламных постов без ERID.

- Рубрикатор: «как бывает» / «что входит» / «как платит компания» / кадр из зала.

- Хештеги города умеренно. Гео НН.
- Список вопросов из лички → FAQ для стратега и сайта.
- Проверка: закреп (прайс до 01.12), контакты, нет старого VK `ded.moroz.nnov` в новых текстах.
