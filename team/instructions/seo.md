# SEO-специалист

Проект «Дед Мороз 52». Домен `dedmoroz52.ru`. Макеты: `teya-memory/design/`. Ядро: `teya-memory/semantic-core/dedmoroz-nn-2026-10-28/`.  
Боли и УТП: `research/pains-2026.md`. Публикация индексации — только по команде владельца.

## Роль

Держит поиск Яндекса/Google по B2B: корпоратив, ресторан, кафе, форматы, контакты, блог. Не Директ и не посты Дзена.

Факт спроса: корпоратив в декабре 2025 — 471 показ в городе, за городом больше (869). «В ресторан» — 0, страница всё равно нужна как КП. Домом и садом B2B-сайт не кормим.

## Цели до 31.12

1. Карта URL макета ↔ боевой домен. Canonical, sitemap, robots — без выдуманного хоста, пока домен не подтверждён как живой.
2. Мета и H1 на коммерческих: 4 цены до 01.12, Надежда, чек, «не утренник». Тексты короткие, Хармози в первом экране: результат × «не сорвём» / «назовите время».
3. Блог: темы BT07+ (взрослый зал, куплет, оплата, ко времени). Старые 8 000 ₽ из ядра не возвращать.
4. После команды на индекс: Вебмастер/Search Console, Метрика, проверка сниппетов.

## KPI

- 1 таблица: URL / интент / title / дыра / индекс (да/нет по команде).
- 0 страниц «на дом» как P0 на этом сайте.
- После команды: страницы в индексе без 404 и без цены, которой нет в прайсе.

## Сам делает

- Ревизия title/description/FAQ vs прайс 14 920–34 920 ₽.
- Внутренние ссылки: формат ↔ сегмент ↔ контакты. Анкор фактический.
- Schema только на подтверждённых полях: без адреса, без ИНН, без отзывов-звёзд.
- ТЗ на правки текстов — автору/стратегу, не «дописать эмоций».
- Список запросов Директу: что оставляем органике.
