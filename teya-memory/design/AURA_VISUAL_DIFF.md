# Visual diff

Сравнивается не чужой сайт, а закон брифа и референс-страница `teya-memory/design/index.html`.

## 1440

- Шапка: имя, город, номер. Совпадает.
- Герой: кадр слева, три карточки справа. Совпадает.
- Переключатель меняет кадр и курсивную строку. Цены 8 000 / 10 000 / 15 000 не меняются. Совпадает.
- Семейной цены нет. Совпадает.
- Кнопки сплошные, клюква. Совпадает.
- Нижняя полоса телефона скрыта. Совпадает с правилом «липкий телефон на мобильном».
- Стык: фото героя визуально доходит до следующей секции. В референсе overlap задан отрицательным margin.

## 768

- Колонки складываются: кадр, затем карточки. Так и задумано, узкая правая колонка на планшете ломала бы состав.
- Номер остаётся доступен в шапке, если влезает. Нижняя полоса включается до 767px, на 768 её ещё нет. Это граница из контракта.

## 375

- Кадр сверху, не ниже зоны чтения строки.
- Карточки столбцом, цена видна без горизонтального скролла.
- Липкая полоса: «Позвонить Надежде» и номер, высота 64px.
- Строка образа не длиннее двух строк.
- Фокус и кнопки не уже 48px по высоте.

## Расхождения, которые оставлены сознательно

- Brand-kit PNG нет. На странице его нет. Это блокер генерации, не дыра в кадре.
- Ансамбль и клуб с чужим знаком в референс не поставлены.
- GSAP на референсе не подключён: затухание сделано CSS 700ms с той же кривой, чтобы страница открывалась без сети. Aurora может взять GSAP для того же жеста.
