# Отзывы — файл для вставки оригиналов

Страница: `otzyvy.html` (алиас: `reviews.html` → редирект).
Данные: `reviews.json` — его читает `reviews.js`. После вставки текста страница обновляется без правки вёрстки.

## Правило

Не выдумывать отзывы, имена, компании и оценки. Публиковать только то, что можно сверить (текст + согласие). Schema.org `Review` появляется только у записей `status: published`.

Источник поиска оригиналов: сообщество прошлой компании [vk.ru/ded.moroz.nnov](https://vk.ru/ded.moroz.nnov). В репозитории на 30 октября 2026 готовых текстов и скриншотов отзывов нет.

## Как добавить отзыв

1. Скопировать слот в `reviews.json` или заполнить существующий `slot-1` … `slot-3`.
2. Поставить `"status": "published"`.
3. Заполнить поля:

```json
{
  "id": "slot-1",
  "status": "published",
  "author": "Анна, HR",
  "consent_to_name": false,
  "event_type": "корпоратив",
  "date": "2025-12-20",
  "text": "Сюда — дословный текст.",
  "photo": "",
  "screenshot": "reviews/shots/slot-1.jpg",
  "rating": null,
  "source_url": ""
}
```

4. Имя компании и фамилия — только если `consent_to_name` = true. Иначе в `author` достаточно имени и типа события.
5. `photo` — только кадр из репозитория (`ded/…`). Сток и сгенерированные лица нельзя.
6. Скриншот оригинала положить в `reviews/shots/` и прописать путь в `screenshot`.

## Карточка на сайте

Поля: фото (если есть), текст, автор, тип события, дата, необязательный скриншот исходного отзыва.
