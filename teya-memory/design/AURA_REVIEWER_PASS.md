# Reviewer pass

Второй проход сделан тем же дизайнером: отдельных субагентов запускать было нельзя. Проверка идёт по закону проекта, не по красоте вообще.

## Вопросы

- Источник не подменён чужим сайтом. Да.
- Формы не приехали из другой задачи: нет кляксы, нет чёрной брутальной рамки, нет снежинок. Да.
- Шрифты с кириллицей, Inter не используется. Да.
- Лишней чёрной обводки нет. Тень карточки мягкая. Да.
- Переключатель не меняет прайс. Да.
- 6 500 ₽ на референсе главной отсутствует. Да.
- Два героя — разные файлы. Да.
- Зоны главной не схлопнуты в один кадр. Да.
- Лица не сгенерированы. Да.
- `gpt-image-2` не подменён другой моделью. Да, блокер записан.
- Эмодзи в интерфейсе нет. Да.
- Контраст кнопок и основного текста выше 4.5:1. Да, см. lint.
- Золото не используется как мелкий текст на ночном фоне. Да.

## Что не сошлось бы, если собрать иначе

Если поставить ансамбль на герой, страница обещает труппу. Если подписать белый зал именем Наршараб, это выдуманный кейс. Если снять фон с пары, кадр перестанет быть залом. Эти ходы отклонены.

Статус прохода: принят с блокером генерации графики, без блокера по живым кадрам.
