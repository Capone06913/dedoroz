# База B2B-лидов «Дед Мороз 52»

Город: **Нижний Новгород** (без области). Сегменты для новогоднего выезда Деда Мороза и Снегурочки.

| Файл | Сегмент |
|------|---------|
| `restaurants-nn.csv` | Рестораны, кафе, банкетные залы, площадки |
| `kindergartens-nn.csv` | Детские сады (муниципальные и частные) и детские центры |
| `companies-nn.csv` | Средний и крупный бизнес с офисом в НН |
| `leads-nn.xlsx` | Те же сегменты на отдельных листах + сводка |

## Колонки

название, адрес, район, телефон, сайт, email, vk, сегмент, подсегмент, **приоритет**, источник, источник_url.

Приоритет: **1** — крупные и премиальные точки (банкет/корпоратив, частные сады, якорные работодатели), **5** — ниже.

## 152-ФЗ

В базе только общие корпоративные контакты: название организации, адрес, район, общий телефон, сайт, общий email (`info@`, `zakaz@`, `dsN_nn@mail.52gov.ru` и аналоги), VK организации, сегмент, URL источника.

Не собираются ФИО сотрудников, именные почты и телефоны, помеченные как личные/директорские.

## Как обновить

```bash
cd leads/scripts
python3 -m pip install -r requirements.txt
python3 fetch_all.py
```

`fetch_all.py` тянет Яндекс Карты, mdoy.pro и Firmoteka, затем обогащает сайты и собирает CSV/XLSX. Выгрузка 2ГИС кладётся в `raw/2gis-*.json` (см. `fetch_2gis.py`).
