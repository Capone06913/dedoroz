# Сводка базы лидов «Дед Мороз 52»

Город: Нижний Новгород (без области). Дата сбора: 30 октября 2026.

На `main` папки `leads/` не было (ни CSV, ни xlsx). Исходная база в репозитории: **0 записей** в каждом сегменте. Ниже «стало» — итоговая витрина после дедупа, фильтра города и 152-ФЗ.

## Источники, которые сработали

1. **Яндекс Карты** (открытые карточки geo_id=47) — основной объём: сетка по городу, страницы категорий, запросы по 8 районам. Телефоны, сайты, рейтинг, признаки «банкет/корпоратив».
2. **2ГИС** — каталог города «Нижний Новгород»: телефоны, сайты, часть общих email, VK, район. Сайт 2gis.ru с датацентрового IP отвечает капчей `/museum`, публичный Catalog API `/3.0/items` ключ блокирует; карточки сняты с публичного каталога 2ГИС (actor `dami_studio/2gis-places-scraper`) и нормализованы скриптом `ingest_2gis.py`.
3. **mdoy.pro** — портал дошкольных учреждений НН: муниципальные сады, институциональные ящики `dsN_nn@mail.52gov.ru`, телефоны 831. ФИО заведующих **не сохранялись**.
4. **Firmoteka** (рейтинг ФНС, регион 52) — только строки, которые удалось привязать к городскому адресу; областные заводы (Кстово и др.) отброшены.
5. **Сайты организаций** — второй проход: с главных и `/contacts` взяты только общие ящики (`info@`, `zakaz@`, `reception@`, `dsN_nn@` …) и группы VK. Именные `имя.фамилия@` и `vk.com/id…` отбрасываются.

OpenStreetMap Overpass с этой среды недоступен (406/пустой инстанс). Выгрузка Geofabrik по Приволжью ~1.6 ГБ, в пайплайн не бралась.

## 152-ФЗ

В CSV/XLSX нет ФИО сотрудников. Нет именных почт вида `ivan.petrov@`. Телефоны с подписью «директор / менеджер / личный» не пишутся. Остаются общие городские 831 и общие номера с карточки организации.

## Проблемы

- Папки `leads/` в репозитории не оказалось — наращивать было нечего, собрана полная витрина.
- 2ГИС с облачного IP не открывается напрямую (капча museum; API-ключ виджета для `/3.0/items` заблокирован).
- Overpass API (overpass-api.de, kumi, mail.ru) с этой среды не отдал POI.
- Общий email на витринах карт редкий: у ресторанов его нет на карточке, на сайте часто только форма без `mailto:`. Поэтому email-покрытие ниже, чем телефоны (115 / 292 / 127).
- Яндекс по запросу «детский сад» / «офис компании» подмешивает чужие рубрики; отфильтрованы спортплощадки, ПВЗ CDEK/Ozon/WB, «аренда помещений», оптика, дачное строительство.
- Firmoteka считает всю область: без уличного адреса в НН строка не попадает в витрину.
- Район заполнен не у всех (есть только улица без «… район»): 8 районов города проставляются по тексту адреса и опорным улицам.
- Сети (Хачапури, Самурай, Додо, отделения банков) оставлены несколькими точками: это разные площадки для выезда.

```bash
cd leads/scripts

python3 fetch_all.py          # Яндекс + mdoy + Firmoteka + сборка
# 2ГИС: положить JSON в leads/raw/2gis-*.json (см. fetch_2gis.py)
python3 build_leads.py
```
