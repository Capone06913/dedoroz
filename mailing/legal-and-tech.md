## 1. Что говорит закон
**38-ФЗ «О рекламе», ст. 18 ч. 1**: распространение рекламы по сетям электросвязи (email, мессенджеры, SMS, звонки) допускается только с предварительного согласия абонента; бремя доказывания согласия — на рекламораспространителе. Штраф по ст. 14.3 КоАП (для юрлиц до 500 тыс. ₽ ⚠️ сверить актуальную редакцию). Обязанность немедленно прекратить рассылку по требованию адресата.
- Позиция ФАС/практика: **индивидуальное деловое предложение конкретному юрлицу**, адресованное конкретному получателю, с текстом под него, не рассчитанное на неопределённый круг лиц, — **не реклама** (нет признака «неопределённого круга»). Массовая одинаковая рассылка по базе — реклама, нужно согласие.
- Значит, для холодного первого касания: письмо персонализировано (название заведения, обращение, повод), отправка небольшими партиями вручную/полуавтоматически, с корпоративного ящика, с понятным «ответьте или откажитесь». Это снижает, но не исключает риск ⚠️.
- Маркировка ERID (ст. 18.1) — касается интернет-рекламы; индивидуальная переписка/email-рассылка по своей базе обычно не маркируется ⚠️ уточнить с ОРД при сомнении. Посты/таргет ВК — маркировать обязательно.

**152-ФЗ «О персональных данных»**:
- Общий адрес заведения (info@, banket@, reserve@restoran.ru), опубликованный самой компанией, — контакт юрлица; ПДн почти нет. **Предпочтительный источник.**
- Именной адрес (ivan.petrov@…), ФИО менеджера, личный мобильный — **персональные данные**. С 01.03.2021 общедоступность ≠ согласие на обработку (ст. 10.1 — распространение нужно согласие на распространение). Собирать именные контакты из интернета без основания — риск. Основание может быть: контакт дал сам (визитка, выставка, звонок, форма на сайте с чекбоксом согласия).
- Если храним хоть какие-то ПДн: политика обработки ПДн на dedmoroz52.ru, уведомление Роскомнадзора об обработке ПДн (с 30.05.2025 штрафы ужесточены ⚠️), хранение базы на серверах в РФ (локализация, ч. 5 ст. 18), удаление по запросу.

## 2. Как собрать базу честно (порядок)
1. Источник — официальные сайты ресторанов, страницы «Банкеты/Контакты»: брать только корпоративные адреса и общий телефон. В таблице фиксировать: название, адрес, источник (URL), дата сбора, тип контакта (общий/именной).
2. **2ГИС / Яндекс Карты** — использовать как справочник для ручного поиска заведений и перехода на их сайт. ⚠️ Автоматический парсинг/выгрузка запрещены пользовательскими соглашениями обоих сервисов; покупные «базы из 2ГИС» не брать (нет согласий, часто ПДн и мёртвые адреса → жалобы и бан домена).
3. Тёплые каналы с согласием: форма «Стать партнёром» на сайте (чекбокс согласия на ПДн + отдельный на рекламные сообщения), звонок Надежды с вопросом «можно прислать КП на почту?» (= согласие, зафиксировать дату), ВК-сообщество (подписка на рассылку через приложение «Рассылки» = согласие).
4. Объём: Н. Новгород — сотни, а не тысячи заведений; 30–50 писем в день с персонализацией — нормально и безопаснее.
5. Отказ/«не пишите» → стоп-лист навсегда.
6. Запреты: купленные базы, парсеры, скрытие отправителя, вводящие в заблуждение темы («Re:» без переписки, «Ваш заказ»), отправка на личные номера в мессенджерах без согласия.

## 3. Сервисы рассылок (российские, серверы в РФ)
| Сервис | Для чего | Заметки |
|---|---|---|
| **Unisender** | основная массовая рассылка по базе с согласием, цепочки (триггеры) | есть бесплатный тариф для небольшой базы ⚠️ проверить лимиты; запрещает холодные/купленные базы — модерация может заблокировать |
| **DashaMail** | альтернатива, хорошая доставляемость, B2B | также требует подтверждённых согласий |
| **Sendsay** | крупнее, сложная автоматизация | избыточен для сезона из ~сотен адресов |
| Яндекс 360 для бизнеса (почта на домене) | холодные **персональные** письма 1-к-1 с ящика вида nadezhda@dedmoroz52.ru | правильный канал для первого касания; лимиты отправки ящика ⚠️ |
Рекомендация: первое касание — вручную/из почты Яндекс 360 с домена; в Unisender/DashaMail грузить только тех, кто ответил/согласился (письма 2–3 и дальнейшая коммуникация). Тарифы и лимиты — уточнять на сайтах сервисов на дату запуска.

## 4. MAX для бизнеса
- Бизнес-аккаунты/каналы и боты в MAX — через платформу для бизнеса (верификация организации, ⚠️ условия доступа для самозанятых проверить на dev.max.ru / business.max.ru).
- Бот может писать только пользователю, который **сам начал диалог** (/start) или подписался — холодная рассылка по номерам невозможна и противоречит 38-ФЗ.
- Сценарий: QR/ссылка на бота в письмах, на сайте, в ВК → ресторан сам нажимает «Старт» → цепочка из max-messages.md. Обязательна кнопка «Отписаться».
- Не спамить, частота — не чаще 1 сообщения в 4–5 дней; канал для ресторанов можно вести как новостную ленту.

## 5. DNS для dedmoroz52.ru
Предпосылка: почта на домене (рекомендуется Яндекс 360) + Unisender. Сейчас контакт — ded.moroz.nnovgorod@yandex.ru; с личного @yandex.ru через Unisender отправлять нельзя (DMARC Яндекса) — нужен адрес на домене, напр. nadezhda@dedmoroz52.ru.

### SPF (одна TXT-запись на корне, не две!)
```
Имя: @        Тип: TXT
v=spf1 include:_spf.yandex.net include:spf.unisender.com ~all
```
(DashaMail/Sendsay — добавить их include из личного кабинета; не более 10 DNS-lookup.) ⚠️ include Unisender сверить в ЛК → «Домены отправителя».

### DKIM
Яндекс 360 (ключ генерирует Яндекс в админке, раздел «Почта → DKIM-подписи»):
```
Имя: mail._domainkey     Тип: TXT
v=DKIM1; k=rsa; t=s; p=<КЛЮЧ_ИЗ_ЯНДЕКС360>
```
Unisender (селектор и ключ выдаёт сервис при подтверждении домена):
```
Имя: <селектор_из_Unisender>._domainkey   Тип: TXT
v=DKIM1; k=rsa; p=<КЛЮЧ_ИЗ_UNISENDER>
```
(или CNAME, если сервис предлагает CNAME-вариант — тогда делать именно так.)

### DMARC (поэтапно)
```
Имя: _dmarc    Тип: TXT
Старт (2–4 нед):  v=DMARC1; p=none; rua=mailto:dmarc@dedmoroz52.ru; fo=1; adkim=r; aspf=r
Затем:            v=DMARC1; p=quarantine; pct=100; rua=mailto:dmarc@dedmoroz52.ru
```
Плюс: MX Яндекс 360 (`mx.yandex.net`, приоритет 10), верификационная TXT Яндекса, отдельный ящик/алиас для rua. Проверка: mail-tester.com, Яндекс Постмастер (postoffice.yandex.ru), Gmail Postmaster.

### Прогрев домена (сезон короткий — начинать сразу)
1. Неделя 0: DNS, ящики на домене, политика ПДн на сайте, ссылка отписки работает. Сайт dedmoroz52.ru должен открываться (сейчас не запущен — домен без сайта снижает доверие).
2. Дни 1–3: 5–10 живых писем/день (свои, партнёры, коллеги — с ответами).
3. Дни 4–7: 20–30/день, персональные письма ресторанам.
4. Неделя 2: 50–80/день; затем +50% в день при жалобах < 0,1% и отказах < 2%.
5. Не слать вложения (КП — ссылкой или HTML), один домен ссылок, текст ≥ 30% от объёма, alt у картинок, List-Unsubscribe (Unisender ставит сам).
