# HTML-письмо (отдельно от сайта)

Макет повторяет **ваш референс** (`images/______________________________________-44a496fc….jpg`): шапка на бордо, герой с живым фото, блок «кто мы» + таблица сравнения **до** карточек с ценами, четыре формата **с фото**, залы, футер с контактами.

## Файлы

- `index.html` — превью и «Скопировать HTML»
- `images/hero-live.jpg`, `about-pair.jpg`, `fmt-*.jpg`, `venue-*.jpg`, `with-guests.jpg` — **живые** кадры (не Kie)

## Запуск

Откройте `index.html` в браузере или `python -m http.server 8791` из этой папки → `http://127.0.0.1:8791/index.html`

## Рассылка

1. Залейте `images/` на хостинг с публичным URL.
2. Вставьте URL в поле «URL папки images/».
3. Скопируйте HTML → Unisender / Яндекс / исходный HTML в почте.
4. Тест себе: Gmail + Яндекс + Outlook.
