# HTML-письмо КП для ресторанов и HR (`email-kp/`)

Премиальное коммерческое предложение в стиле сайта `dedmoroz52.ru` (минимализм, много воздуха, табличная вёрстка **600px**, 100% инлайн-стили).

## Что внутри письма

1. **Скрытый Preheader** — краткий оффер для превью в списке писем почтового клиента (Gmail, Яндекс Почта, Apple Mail, Outlook).
2. **Первый экран (Hero)** — живое фото выступления, позиционирование дорогого B2B-подрядчика по формуле ценности Хармози («результат × уверенность / минимум усилий: вы только называете время») и русскоязычный CTA «Проверить свободную дату» (168-ФЗ).
3. **Блок «Что обычно идёт не так — и как мы это закрываем»** — 6 главных болей корпоративных заказчиков и управляющих залов (стишки/утренник, опоздания, нетрезвый артист, отсутствие звука и слом подачи горячего, дешёвый костюм, рост цены и отсутствие чека) с конкретной гарантией под каждый пункт.
4. **Блок «Выберите свой формат»** — 4 чистые карточки форматов с живыми фото и фиксированными ценами до 1 декабря 2026:
   - **Собирает весь зал** (20–25 мин) — **14 920 ₽**
   - **Поющие артисты** (30 мин, живой вокал) — **19 920 ₽**
   - **Праздник с порога** (60 мин: встреча гостей + шоу) — **24 920 ₽**
   - **Лично у каждого стола** (60 мин, персональный обход) — **34 920 ₽**
   - Плюс партнёрская комиссия **10–15% ресторанам** при сохранении цены для гостя.
5. **Блок «5 пар — 5 сценических образов»** — лаконичная витрина 5 стилей костюмов без визуального перегруза чужих PDF-слайдов + список реальных площадок Нижнего Новгорода («Ариэль», «Колокол», «Наршараб», «Онегин»).

## Файлы

- `index.html` — интерактивный генератор и превью письма (можно выбрать сегмент «Ресторан» / «HR» / «Универсальное», вписать название площадки и скопировать готовый HTML-код).
- `kp-email-600.html` — готовое автономное HTML-письмо шириной 600px для прямой отправки и вставки в рассыльщик.
- `images/` — живые фотографии с реальных выступлений.
